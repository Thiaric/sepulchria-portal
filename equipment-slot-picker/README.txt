SEPULCHRIA — CLICKABLE EQUIPMENT SLOT PICKER

No SQL required.

Empty Equipment slots become clickable. The picker shows only loose,
unequipped Items configured for that slot. Selecting one shows its image,
brief description, passive bonuses, requirements, and an Equip button when
eligible.

Passive bonuses shown:
Muscles, Reflexes, Vigour, Shrewd, Brains, Presence, Max Health.

INSTALL
1. Extract into repository root.
2. Run:
   py .\equipment-slot-picker\install.py
3. Run:
   npm run build
4. Restart dev if needed.
