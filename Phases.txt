# PHASE 9 — Testing & QA

Now test Sepulchria as a **game**, not individual pages.

### 9.1 — Automated testing

Prioritise critical systems:

* Authentication.
* Character lifecycle.
* Market.
* Trading.
* Inventory.
* Combat.
* Magic.
* Missions.
* Rewards.
* Reports.
* Permissions.


### 9.4 — Staff lifecycle test

Test moderation and administration using actual non-owner staff accounts.

### 9.5 — Browser/device testing

At least:

* Chrome.
* Edge.
* Firefox.
* Safari where practical.
* Common desktop resolutions.
* Mobile/tablet behaviour if we intend to support them.

### 9.6 — Failure testing

Deliberately:

* Refresh during actions.
* Lose connection.
* Double-submit.
* Open multiple tabs.
* Navigate backwards.
* Use stale pages.
* Submit invalid IDs.
* Attempt unauthorised URLs/actions.

**Phase 9 complete when:** the portal survives people using it incorrectly, not just correctly.

# PHASE 11 — CLOSED ALPHA

Small trusted group.

Do **not advertise broadly yet**.

Test real roleplay behaviour for a few weeks and collect:

* Bugs.
* UX complaints.
* Missing staff tools.
* Balance problems.
* Confusing rules.
* Unexpected player behaviour.

Fix critical problems.

---

# PHASE 12 — BETA

Larger invited player population.

Focus on:

* Economy balance.
* Combat balance.
* Progression speed.
* Server/database load.
* Moderation workload.
* Mission/event workflow.
* New-player comprehension.

Freeze major architectural changes unless absolutely necessary.

## The roadmap in one line

**NOW → Codex & Rules → Support/Reports → Magic → Combat → Missions/Progression → World/NPCs → Staff/Permissions → Full Engineering Audit → QA → Content/Launch Prep → Closed Alpha → Beta → Launch**

And importantly, **Items / Inventory / Equipment / Remnants / Market are no longer a future phase**. They're built. Rules, Areas and Events aren't future greenfield systems either; they need completion/auditing rather than reconstruction.

This is the roadmap I'd use from this point onward as the **master development plan for Sepulchria Portal**.
