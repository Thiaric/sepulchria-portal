SEPULCHRIA — MARKET ITEM DETAILS

Adds mechanical Item information to /market/[shop].

Shows, where applicable:
- Equippable + slot
- One-hand / two-hand
- Usable
- Consumable / reusable / limited charges
- Target mode
- Cooldown
- Healing
- Attribute modifiers
- Max Health modifiers
- On use / while equipped / while owned
- Temporary duration
- Quest Item

No SQL required.

Run:
  py .\market-item-details\install.py
  npm run build
